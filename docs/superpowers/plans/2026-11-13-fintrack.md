# FinTrack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full-stack personal finance app (portfolio piece) with a public demo on Vercel + Neon.

**Architecture:** npm-workspaces monorepo. `server/` is an Express app (exported, not listening) using Prisma 7 + `@prisma/adapter-pg`; `api/index.ts` re-exports it as one Vercel Node function; `web/` is a Vite React SPA calling `/api/*` on the same origin. Auth is a JWT in an httpOnly cookie.

**Tech Stack:** Node ≥22, TypeScript, Express 5, Prisma 7, PostgreSQL, Zod, bcryptjs, jsonwebtoken, cookie-parser · React 19, Vite, Tailwind 4, TanStack Query, React Router, React Hook Form, Recharts, jsPDF + jspdf-autotable, exceljs · Vitest, Supertest, embedded-postgres (local DB, no Docker on this machine).

**Spec:** `docs/superpowers/specs/2026-11-13-fintrack-design.md`

## Global Constraints
- Money is integer **cents** everywhere (DB, API, front state). Format only at render (`Intl.NumberFormat('pt-BR', {style:'currency', currency:'BRL'})`).
- Every query on user data filters by `req.userId`; a foreign id returns **404**, never 403 (no existence leak).
- All request bodies/queries validated with Zod; error shape `{ error: string, details?: unknown }`.
- Cookie `token`: httpOnly, `SameSite=Lax`, `Secure` when `NODE_ENV=production`, 7 days.
- UI copy and README in pt-BR; code, identifiers, commits in English.
- Env vars: `DATABASE_URL`, `JWT_SECRET`, `CRON_SECRET`.
- Nothing referencing the author's employer or its systems.

## Review Focus
1. Brazilian CSV quirks: BOM, `;` vs `,`, `1.234,56`, `-50,00`, `(50,00)`, blank trailing lines → parsed or row flagged, never a crash. (Task 6 tests)
2. User A requesting/updating/deleting user B's account/transaction/category/budget → 404. (Task 3/4/5 tests)
3. Deleting an account or category that has transactions → 409 with message, not a FK 500. (Task 3 tests)
4. Month boundaries: transaction on the last day 23:59 local belongs to that month; dates stored as `@db.Date` strings `YYYY-MM-DD`, no timezone shift. (Task 4/5 tests)
5. Guest cleanup must never delete non-guest users. (Task 2 test)

## API contract (all under `/api`, JSON, auth required unless noted)

| Method | Path | Body / query | Response |
|---|---|---|---|
| GET | `/health` (public) | — | `{ ok: true }` |
| POST | `/auth/register` (public) | `{name, email, password(min 8)}` | 201 `User` + cookie |
| POST | `/auth/login` (public) | `{email, password}` | `User` + cookie; 401 on bad creds |
| POST | `/auth/guest` (public) | — | 201 `User` (isGuest) + cookie, seeded |
| POST | `/auth/logout` | — | 204, clears cookie |
| GET | `/auth/me` | — | `User` |
| GET/POST | `/accounts` | `{name, type, initialBalance}` | `AccountWithBalance[]` / 201 |
| PATCH/DELETE | `/accounts/:id` | partial | `Account` / 204 (409 if has tx) |
| GET/POST | `/categories` | `{name, color, kind}` | `Category[]` / 201 |
| PATCH/DELETE | `/categories/:id` | partial | / 204 (409 if has tx) |
| GET | `/transactions` | `from,to,accountId,categoryId,kind,q,page(1),pageSize(20,max 100),sort(date\|amount),order(asc\|desc)` | `{ items, total, page, pageSize }` |
| POST | `/transactions` | `{accountId, categoryId, kind, amount(>0 int), date(YYYY-MM-DD), description}` | 201 |
| PATCH/DELETE | `/transactions/:id` | partial | / 204 |
| POST | `/transactions/import` | `{accountId, rows: {date, description, amount(signed int), categoryId?}[] (max 2000)}` | `{ imported: number }` |
| GET/PUT | `/budgets?month=YYYY-MM` | PUT `{categoryId, month, limit}` (upsert) | `BudgetWithSpent[]` |
| DELETE | `/budgets/:id` | — | 204 |
| GET | `/dashboard?month=YYYY-MM` | — | `Dashboard` |
| GET | `/cron/cleanup` (header `Authorization: Bearer $CRON_SECRET`) | — | `{ deleted: number }` |

Types (`server/src/types.ts`, mirrored in `web/src/api/types.ts`):
- `User = {id, name, email, isGuest}`
- `AccountWithBalance = Account & { balance: number }` (initialBalance + incomes − expenses)
- `BudgetWithSpent = Budget & { spent: number, category: Category }`
- `Dashboard = { totalBalance, monthIncome, monthExpense, byCategory: {categoryId,name,color,total}[], last12Months: {month, income, expense}[], recent: Transaction[] }`
